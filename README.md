# Ran — Micro-Gold App

A responsive React + TypeScript interface for Ran with two product surfaces:

- User micro-gold wallet and shop offers


## Run locally

```bash
npm install
npm run dev
```

## Separate panels

Open each interface at its own route:

- User panel: `http://localhost:5173/#user`
- Admin panel: `http://localhost:5173/#admin`

## Production build

```bash
npm run build
```
